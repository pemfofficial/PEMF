PEMF - Pirates! Expanded Modding Framework


INSTALLING
----------

1. Find your game folder - the one containing Pirates!.exe.

       GOG     C:\GOG Games\Sid Meier's Pirates\
       Steam   C:\Program Files (x86)\Steam\steamapps\common\Sid Meier's Pirates!\

   In Steam you can get there with:
       right-click the game -> Manage -> Browse local files

2. Copy everything from this archive into that folder.

   You should end up with version.dll and pemf_core.dll sitting beside
   Pirates!.exe, and a new PEMF folder next to them.

   *** WATCH OUT FOR THIS ONE ***

   Windows' own "Extract All" does NOT put the files where you point it. It
   creates a SUBFOLDER named after the zip and puts them in there, so you end
   up with:

       Sid Meier's Pirates!\PEMF-0.2.3\version.dll        <- wrong, does nothing

   instead of:

       Sid Meier's Pirates!\version.dll                   <- right

   If you are UPGRADING, this is worse than nothing: the old DLLs are still
   sitting in the game folder, so the game keeps running the OLD version while
   you are certain you installed the new one.

   The safe way is to open the zip, select all, and drag the files into the
   game folder - or extract anywhere you like and then move version.dll,
   pemf_core.dll and PEMF into place yourself.

3. Launch the game as you normally would.

That is all. The game executable is never modified.


UPGRADING FROM AN EARLIER VERSION
---------------------------------

Extract straight over the top. Your saves, your key bindings and your edited
.ini files are all left alone.

Both DLLs must come from the SAME zip. If they do not, pemf.log says so in
capitals on the third line - see below.


CHECKING IT WORKED
------------------

A file called pemf.log appears in the game folder the first time you run it.
Open it. The first lines tell you:

    - which version of PEMF is running, and when it was built
    - whether version.dll and pemf_core.dll are the same version
      (a line beginning "*** MIXED INSTALL" means they are not, and that
       you have the subfolder problem described above)
    - which build of the game was detected, and whether every engine
      address verified

If something is wrong it says so in plain English.


UNINSTALLING
------------

Delete version.dll, pemf_core.dll and the PEMF folder. Nothing else was
touched.

If you want your original key bindings back, PEMF saved them as
KeyMap.ini.pemf-backup, next to the KeyMap.ini it replaced. That is in your
Documents folder under My Games - and the folder name depends on which copy of
the game you own:

    Steam   My Documents\My Games\Sid Meier's Pirates!\
    GOG     My Documents\My Games\Sid Meier's Pirates\

Rename the backup over KeyMap.ini. (pemf.log names the folder PEMF chose, if
you are not sure which is yours.)


WHAT CHANGES IMMEDIATELY
------------------------

WASD steering, in every part of the game - sailing, ship battles, land
battles, duels, sneaking. Two keys had to move to make room:

    Attack ship   was 'a'   now Space
    Quick save    was 'S'   now F5      (quick load is now F9)

PEMF writes this once, keeps a backup, and never touches the file again - so
anything you rebind afterwards stays rebound.


PLAYING FALSE FLAG
------------------

    Ctrl+Shift+8    run up a different flag
    Ctrl+Shift+9    run your own colours back up
    Ctrl+Shift+0    write a report to pemf.log

Fly another nation's flag and a meter appears in the top right. It fills while
their ships and ports can see you, and empties in open water. Fill it and they
see through you - your reputation with them drops, your colours are struck, and
they send pirate-hunters after you.

Sail away and the trail goes cold. The further you get, the faster it cools.

Tuning lives in PEMF\suspicion.ini. It is commented, and a reinstall will not
overwrite one you have edited.


REPORTING A PROBLEM
-------------------

Send pemf.log along with a sentence about what you were doing. The log is
where everything useful is.


BOTH STORE VERSIONS ARE SUPPORTED
---------------------------------

GOG and Steam both work. The Steam executable is compressed on disk, so PEMF
waits for it to unpack before touching anything and verifies every address it
uses at runtime.

The Challenge Pack executable is a DIFFERENT build of the game and is not
supported. PEMF detects it and disables itself rather than risk your save.
