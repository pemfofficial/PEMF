**What's next for PEMF**

Honest confidence levels. **Proven** means we've done it in a running game. **Designed** means we know how and haven't built it. **Exploring** means we don't know yet.

**Finishing False Flag**
• Starting under your own faction's colours — the English-flag artefact you'll have noticed. *Designed, unblocked.*
• A per-captain flag chosen at career start instead of one global setting. *Designed.*
• Hunters that truly chase rather than sail toward you. Today they're re-aimed every few seconds, which reads as pursuit but isn't. *Designed.*
• Lowering the old flag and raising the new one on the mast. *Exploring — flags are named scene nodes, so it's plausible.*

**Sound**
Adding new sounds, not just replacing the game's. The game loads loose `.wav` files by name and we can already play its own audio on cue, so this is close. Pairing a spoken callout with the floating "Land ho!" is the first target. *Designed.*

**Crew & officers**
Named officers who persist, remember, and have opinions. Crew as a body with morale that splinters into mutiny. This is the biggest piece and the one PEMF was originally started for. *Designed.*

**Trade goods**
The game's 7 cargo slots are hard-boxed — an 8th *engine* slot isn't worth pursuing, we checked. But new goods can live in PEMF's own memory with our own UI, and their names already come from an editable file. *Designed.*

**World**
More regions than the Caribbean. The map is a fixed grid with 128 settlement slots and the "you've strayed too far" boundary is a clean place to hook a zone transition — each region keeping its own map and towns. *Exploring, and the most speculative thing here.*

**Ruled out**
An 8th trade good in the engine's own array. The ship-nationality field as an AI lever. Both written up in the repo with the evidence — the failures are documented as carefully as the wins.

Every investigation, including the dead ends, is public: **github.com/pemfofficial/PEMF**
