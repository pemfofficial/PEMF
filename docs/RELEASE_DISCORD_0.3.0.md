**PEMF 0.3.0 — The Black Flag is out!**

**New:** start as a pirate in a pirate haven · earn flags (letters of marque, tavern seller, Q to switch colours) · suspicion based on how each crown sees you · pirate-hunters only from crowns that hate you · waterfront in every port (bribes, gossip, hiring) · a moving market · louder, smokier sea battles + a battle song · changing wind and drifting storms · widescreen, hi-res and HUD in the corners.
